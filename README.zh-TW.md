# Twitch 彈幕

[English](README.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md)

把 Twitch 直播間的聊天，直接變成畫面上的彈幕，直播看起來更有氣氛，也不用一直盯著聊天室。這套油猴腳本支援互動暫停、可選即時翻譯，還是零外部依賴，對想把直播畫面做得更有 vibe 的觀眾來說，真的很順手。

## 功能

- **即時彈幕** — 新聊天訊息會直接在播放器畫面上滾動顯示（直播與重播 video chat 都支援）
- **發送者配色** — 只顯示內容，不同使用者會有不同顏色，畫面看起來更有節奏
- **互動暫停** — 滑鼠懸停或點擊時暫停；點擊可以看發送者資訊（翻譯彈幕會顯示原文）
- **複製到聊天框** — 點擊彈幕後，在彈窗中點擊複製按鈕，將彈幕內容貼到右側聊天輸入框
- **自訂設定** — 速度、字體、透明度、滾動區域（全螢幕 / 上半部 / 下半部 / 頂部 1/4）都能調
- **彈幕朗讀** — 可選朗讀每則彈幕，能調聲音與語速；太長時自動加快。開啟翻譯後讀譯文
- **Super Chat 懸停** — Cheers、Prime／層級訂閱（含續訂留言）、高亮與置頂訊息可固定；位置可選頂／底居中或四角，可疊在滾動彈幕上。顯示頭像、徽章等，多則並排，過長正文滾動。滑鼠移上暫停；可提前關閉
- **增強畫中畫** — 控制列可開啟可縮放小窗，同步彈幕，側欄可開關彈幕與設定，支援聊天輸入與收藏
- **收藏彈幕 & 獨輪車** — 輸入框旁星標儲存常用話術，一鍵發送或數字快捷鍵（可區分本直播間／全站）；獨輪車模式依間隔隨機發送收藏。發送失敗會提示原因，不會誤報成功
- **聊天右鍵選單** — 右鍵聊天訊息可翻譯／重新翻譯、朗讀、重新發送彈幕、加入收藏，或屏蔽該使用者
- **清空直播聊天** — 聊天室頂欄提供清空按鈕
- **全螢幕發訊息** — 直播全螢幕時按 Enter 喚起輸入條；可用收藏按鈕快速填入。發送受限時在下方顯示原因。內容為空時點外側或紅色關閉按鈕可收起（不會退出全螢幕）
- **噪音過濾** — 忽略常見機器人、分隔線、純連結，以及連續觀看、頻道點數等無使用者正文的系統通知（僅真實聊天與 Bits／訂閱 Super Chat 會進入彈幕、翻譯與朗讀）
- **屏蔽使用者列表** — 設定面板可查看、新增、取消 Twitch 原生屏蔽
- **聊天紀錄下載** — 直播頁匯出目前聊天面板裡已載入的訊息；重播頁從 Twitch 拉取歷史聊天。支援 JSON / CSV / TXT，可依關鍵詞、使用者名稱、Super Chat 篩選，重播還可選時間範圍
- **全螢幕自適應** — 窗口縮放與全螢幕時會自動調整，不卡版
- **即時翻譯** — Microsoft、Google、火山翻譯、彩雲小譯、騰訊互動翻譯；聊天高峰會合併請求並自動換引擎，純數字／符號不翻。可選在聊天室訊息下方用 Twitch 紫色樣式顯示譯文
- **防堆積** — 進入直播間或切回分頁時不會爆量刷屏；可選「防分頁凍結」，減輕背景時聊天與播放器被掛起（增強畫中畫開啟時自動啟用）
- **雙語介面** — 會自動判斷瀏覽器語言，中文／英文都能順手使用

## 安裝

1. 安裝 [Tampermonkey](https://www.tampermonkey.net/)
2. 選一種方式安裝：
   - **Greasy Fork（推薦）** — 前往 [Twitch Danmaku on Greasy Fork](https://greasyfork.org/en/scripts/586579-twitch-danmaku) 點擊安裝
   - **手動安裝** — 把 [dist/twitch-danmaku.user.js](dist/twitch-danmaku.user.js) 的內容複製下來，在 Tampermonkey 新增腳本貼上後存檔
3. 確認瀏覽器設定裡有開啟開發者模式

或是從原始碼自己 build：

```bash
git clone https://github.com/saka1zum1/twitch-danmaku.git
cd twitch-danmaku
npm run build
```

## 使用方式

1. 打開任意 Twitch 直播間或重播頁（`/videos/…`）
2. 新的聊天訊息會自動變成彈幕出現在畫面上（重播頁讀取同步的 video chat）
3. 播放器控制列上的按鈕：
   - **彈幕按鈕** — 開關彈幕
   - **翻譯按鈕** — 一鍵開關即時翻譯（與設定面板同步）
   - **朗讀按鈕** — 打開朗讀設定
   - **下載按鈕** — 匯出直播面板聊天或重播歷史聊天
   - **設定按鈕** — 打開設定面板
   - **增強畫中畫** — 開啟可縮放小窗（Chrome / Edge 116+）
4. 懸停在彈幕上時會暫停；點一下可以看發送者資訊
5. 點 tooltip 裡的複製按鈕，把彈幕內容貼到 Live Chat 輸入框
6. 滑鼠移開 0.3 秒後，彈幕就會繼續滾動（懸停）；點擊鎖定後，需點擊彈窗與該彈幕以外的區域才會恢復

## 設定項目

| 項目 | 說明 |
|------|------|
| 滾動速度 | 1–10，數字越大越快 |
| 字體大小 | 14–40 px |
| 彈幕透明度 | 10–100% |
| 字體 | 18 種系統字體可選 |
| 滾動區域 | 全螢幕 / 上半部 / 下半部 / 頂部 1/4 |
| 啟用翻譯 | 彈幕畫面上顯示翻譯內容 |
| 聊天室顯示譯文 | 在聊天訊息下方顯示譯文，Twitch 紫色樣式與原文區分 |
| 翻譯引擎 | 自動切換 / Microsoft / Google / 火山翻譯 / 彩雲小譯 / 騰訊互動翻譯 |
| 目標語言 | 來源語言會自動偵測 |
| 翻譯速度 | 1–10 條／秒。高峰時多則訊息會合成一次請求，避免打滿單一引擎 |
| 關鍵詞屏蔽 | 原文或譯文包含關鍵詞時不顯示彈幕 |
| 屏蔽使用者列表 | Twitch 原生屏蔽：在面板中查看、新增或取消屏蔽 |
| 彈幕朗讀 | 朗讀每則彈幕。開啟翻譯後朗讀譯文 |
| Super Chat 懸停 | 固定 Cheers、Prime／層級訂閱、高亮與置頂訊息；位置與動畫可調，可疊在滾動彈幕上。滑鼠移上暫停；可提前關閉 |
| 防分頁凍結 | 可選：背景時盡量保持頁面「可見」，減輕聊天與播放器被瀏覽器掛起 |

設定會儲存在本機，重新整理後也會保留下來。

## 聊天紀錄

在直播頁或重播頁（網址包含 `/videos/`）使用播放器上的下載按鈕。

- **直播** — 匯出目前聊天面板或（偵測到 FrankerFaceZ 時）IRC 緩衝中的訊息（不是完整歷史），無時間範圍
- **FrankerFaceZ** — 直播頁偵測到 FFZ 時，彈幕改由 Twitch IRC 取流，避免與聊天 DOM 衝突
- **重播** — 從 Twitch 拉取歷史聊天，可選時間範圍
- 可依聊天內容關鍵詞、發送者使用者名稱篩選；留空表示不過濾
- 可選擇是否包含 Super Chat（Bits Cheers）
- 匯出 JSON、CSV 或 TXT；重播下載過程中可暫停、繼續或取消
- 若直播面板為空，或 Twitch 已不再保留該重播的聊天，面板會提示

## 開發

```bash
npm run build
npm run watch
```

公開演示不需要建置：[Twitch 彈幕演示](https://saka1zum1.github.io/twitch-danmaku/)。它用頁面代替觀看頁（播放器、控制列、聊天列表）。列表裡已有的訊息不會滾動；預熱結束後新加的訊息會從畫面上飄過。可試用收藏星標、Super Chat（Bits／訂閱）、頂欄清空聊天，以及右鍵聊天列的翻譯／朗讀／重發／收藏／屏蔽。開啟翻譯後可看到演示譯文，以及聊天室裡的紫色譯文行。預覽頁在瀏覽器分頁位於背景時也會繼續跑。

## 注意事項

- 翻譯依賴 Microsoft、Google、火山、彩雲或騰訊服務，某些地區可能需要代理
- 聊天很熱時，腳本會把多則訊息合併翻譯，並暫時換掉被限流的引擎
- Twitch 的 DOM 更新可能會影響相容性，歡迎回報 Issue
