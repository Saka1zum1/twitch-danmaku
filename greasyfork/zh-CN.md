## 简介

**Twitch 弹幕姬** 让你在看 Twitch 直播时，把聊天室里的新消息变成视频上滚动的弹幕——就像 B 站那样。

不用一直盯着右侧聊天框，重要评论从画面上飘过，一目了然。

---

## 使用方法

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展
2. 安装本脚本后，打开任意 Twitch 直播间或回放页（`/videos/…`）
3. 播放器底部控制栏会出现新按钮：
   - **弹幕按钮** — 一键开关弹幕
   - **朗读按钮** — 打开朗读设置
   - **下载按钮** — 导出直播面板聊天或回放历史聊天
   - **设置按钮** — 打开设置面板
4. 在设置面板中调整样式、透明度、关键词屏蔽或开启翻译

**小技巧：** 看到感兴趣的弹幕？鼠标移上去就能暂停阅读；点击还能查看发送者。

## 主要功能

### 实时弹幕
- 自动捕获聊天室新消息，在视频播放器上滚动显示
- 直播与回放页（同步 video chat）均支持
- 只显示消息内容，不同发送者用不同颜色区分
- 悬停或点击任意弹幕可暂停滚动
- 点击弹出弹窗显示发送者，在弹窗中点击复制按钮，将弹幕内容粘贴到右侧聊天输入框

### 自定义样式
- 滚动速度、字体大小、字体种类（18 种系统字体）
- **弹幕透明度** — 10–100% 可调（默认 100%），调整后当前屏幕上的弹幕也会立即生效
- 滚动区域：全屏 / 上半屏 / 顶部 1/4
- 全屏播放、调整窗口大小时自动适配

### 弹幕朗读
- 可在播放器控制栏打开朗读，逐条读出弹幕
- 可调声音、音量、音高和语速。过长时变速模式会自动加快
- 开启翻译后朗读译文。纯符号、纯表情和纯数字不朗读

### Super Chat 悬停
- 识别 Bits Cheers、订阅、带底色的高亮消息和置顶消息
- 显示头像、截断用户名、金额/Sub 徽章，以及 Twitch 欢呼档位配色（1 / 100 / 1000 / 5000 / 10000 / 100000）
- Bits 金额按 cheermote 与图片资源识别（含 Bits 卡片预设 300 / 1000 / 5000 / 10000）；忽略 cheer 徽章，避免误判为 1 Bit
- 多条可同时悬停且互不遮挡；过长正文在气泡内滚动
- 动画可选淡入淡出、滑入、弹出、闪光。悬停会暂停动画并显示发送者；右上角关闭按钮可提前收起

### 聊天右键菜单
- 右键聊天消息：翻译 / 重新翻译（不依赖设置里的翻译开关）、朗读（优先读聊天室已显示译文）、重新发送弹幕、屏蔽该用户（Twitch 原生屏蔽）
- 翻译跟随设置中的引擎（失败自动切换）；朗读跟随朗读面板的声音 / 语速 / 音量

### 清空直播聊天 & 全屏发消息
- 聊天室顶栏提供 Twitch 风格清空按钮，一键清空面板（含 FrankerFaceZ 下的 IRC 缓冲）
- 直播全屏时按 Enter 唤起 Twitch 风格输入条，通过 GraphQL 发送聊天；内容为空时点外侧或点红色关闭按钮可收起，不会退出全屏

### 屏蔽用户列表
- 设置面板可查看、添加、取消 Twitch 原生屏蔽列表

### 聊天记录下载
- **直播** — 导出当前聊天面板或（检测到 FrankerFaceZ 时）IRC 缓冲中的消息（不是完整历史）
- 兼容 FrankerFaceZ：直播页检测到 FFZ 时，弹幕改走 Twitch IRC，不依赖聊天 DOM
- **回放**（`/videos/…`）— 从 Twitch 拉取历史聊天，可选时间范围
- 可按内容关键词和用户名筛选，留空表示不过滤
- 可选择是否包含 Bits Cheers（Super Chat）
- 导出 JSON、CSV 或 TXT；回放下载过程中可暂停、继续或取消
- 若直播面板为空，或该回放已无聊天记录，面板会提示

### 关键词屏蔽
- 在设置面板添加或删除屏蔽词（最多 50 个，不区分大小写，部分匹配）
- **原文**或**译文**包含任一关键词时，该条弹幕不显示
- 原文已命中屏蔽词时，不会再去请求翻译
- 另可在设置中管理 Twitch **用户**屏蔽列表（与关键词屏蔽独立）

### 实时翻译（可选）
- 支持 Microsoft、Google、火山翻译、彩云小译、腾讯交互翻译及自动切换
- 源语言自动检测，译文直接替换弹幕内容
- 可选在聊天室消息下方显示 Twitch 紫色样式的译文（设置面板开关）
- 可自选目标语言与翻译速度

### 贴心细节
- 进入直播间不会刷出一屏历史弹幕
- 切换标签页回来后不会集中爆发
- 界面自动识别浏览器语言（中文 / 英文）
- 零外部依赖，轻量不拖慢页面

## 常见问题

**Q: 翻译不工作？**
A: 翻译依赖 Microsoft、Google 等外部服务，部分地区可能需要网络代理。

**Q: 弹幕太多看不清？**
A: 可在设置中调慢速度、缩小滚动区域、降低透明度，或直接关闭弹幕。

**Q: 关键词屏蔽怎么生效？**
A: 原文或翻译结果里出现你添加的关键词时，该条弹幕会被隐藏。

**Q: 支持哪些浏览器？**
A: 支持 Tampermonkey 的 Chromium、Firefox、Safari 等主流浏览器。

## 隐私说明

- 本脚本仅在 Twitch 页面运行
- 启用翻译时，请求会发往你所选的翻译服务
- 设置（含关键词列表）保存在浏览器本地，不上传任何数据
