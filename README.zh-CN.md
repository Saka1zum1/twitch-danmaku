# Twitch 弹幕

[English](README.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md)

将 Twitch 直播聊天实时转换为视频弹幕的油猴脚本。支持交互暂停、可选实时翻译，零外部依赖。

## 功能

- **实时弹幕** — 聊天新消息在视频播放器上滚动显示（直播与回放 video chat 均支持）
- **发送者配色** — 仅显示内容，不同用户不同颜色
- **交互暂停** — 悬停或点击暂停；点击可查看发送者（翻译弹幕显示原文）
- **复制到聊天框** — 点击弹幕后，在弹窗中点击复制按钮，将弹幕内容粘贴到右侧聊天输入框
- **自定义** — 速度、字体、透明度、滚动区域（全屏 / 上半屏 / 下半屏 / 顶部 1/4）
- **弹幕朗读** — 可选朗读每条弹幕，可调声音、语速；过长时自动加快。开启翻译后读译文
- **Super Chat 悬停** — Cheers、Prime / 层级订阅（含续订留言）、带底色的高亮消息和置顶消息可固定在画面上；悬停位置可选顶部/底部居中或四角，可叠在滚动弹幕之上。显示真实头像、截断用户名、金额 / Prime / Tier 徽章，多条并排，过长正文滚动。悬停暂停；右上角关闭按钮可提前收起
- **增强画中画** — 播放器控制栏可打开可自由缩放的小窗，同步滚动弹幕，侧栏可开关弹幕与设置，支持聊天输入与收藏
- **收藏弹幕 & 独轮车** — 输入框旁星标保存常用话术，一键发送或数字快捷键（可区分本直播间 / 全站）；独轮车模式按间隔随机发送收藏。发送失败会提示原因，不会误报成功
- **聊天右键菜单** — 右键聊天消息可翻译/重新翻译、朗读、重新发送弹幕、加入收藏，或屏蔽该用户
- **清空直播聊天** — 聊天室顶栏提供清空按钮
- **全屏发消息** — 直播全屏时按 Enter 唤起输入条；可用收藏按钮快速填入。发送受限时在下方显示原因。内容为空时点外侧或红色关闭按钮可收起（不会退出全屏）
- **噪音过滤** — 自动忽略常见机器人、分隔线、纯链接，以及连续观看、频道点数等无用户正文的系统通知（仅真实聊天与 Bits/订阅 Super Chat 会进入弹幕、翻译与朗读）
- **屏蔽用户列表** — 设置面板可查看、添加、取消 Twitch 原生屏蔽
- **聊天记录下载** — 直播页导出当前聊天面板里已加载的消息；回放页从 Twitch 拉取历史聊天。支持 JSON / CSV / TXT，可按关键词、用户名、Super Chat 筛选，回放还可选时间范围
- **全屏自适应** — 窗口缩放与全屏时自动调整
- **实时翻译** — Microsoft、Google、火山翻译、彩云小译、腾讯交互翻译，高峰时合并请求并自动换引擎；纯数字/符号不翻译。可选在聊天室消息下方用 Twitch 紫色样式显示译文
- **防堆积** — 进入直播间或切回标签页时不爆发刷屏；可选「防页签冻结」，减轻后台时聊天与播放器被挂起（增强画中画打开时自动启用）
- **双语界面** — 自动识别浏览器语言（中/英）

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)
2. 任选一种方式安装：
   - **Greasy Fork（推荐）** — 访问 [Twitch Danmaku 油猴脚本页](https://greasyfork.org/en/scripts/586579-twitch-danmaku)，点击安装
   - **手动安装** — 复制 [`dist/twitch-danmaku.user.js`](dist/twitch-danmaku.user.js) 中的代码，在油猴扩展中新建脚本并粘贴保存
3. 确保在浏览器设置中启用开发者模式

或从源码构建：

```bash
git clone https://github.com/saka1zum1/twitch-danmaku.git
cd twitch-danmaku
npm run build
```

## 使用

1. 打开任意 Twitch 直播间或回放页（`/videos/…`）
2. 新聊天消息自动变为视频弹幕（回放页读取同步的 video chat）
3. 播放器控制栏按钮：
   - **弹幕按钮** — 开关弹幕
   - **翻译按钮** — 一键开关实时翻译（与设置面板同步）
   - **朗读按钮** — 打开朗读设置
   - **下载按钮** — 导出直播面板聊天或回放历史聊天
   - **设置按钮** — 打开设置面板
   - **增强画中画** — 打开可缩放小窗（Chrome / Edge 116+）
4. 悬停弹幕暂停；点击查看发送者信息
5. 点击 tooltip 中的复制按钮，将弹幕内容粘贴到 Live Chat 输入框
6. 鼠标移出 0.3 秒后恢复滚动（悬停）；点击弹窗和该弹幕以外的区域可恢复（点击锁定后）

## 设置

| 选项 | 说明 |
|------|------|
| 滚动速度 | 1–10，越大越快 |
| 字体大小 | 14–40 px |
| 弹幕透明度 | 10–100% |
| 字体 | 18 种系统字体 |
| 滚动区域 | 全屏 / 上半屏 / 下半屏 / 顶部 1/4 |
| 启用翻译 | 弹幕显示译文 |
| 聊天室显示译文 | 在聊天消息下方显示译文，Twitch 紫色样式与原文区分 |
| 翻译引擎 | 自动切换 / Microsoft / Google / 火山翻译 / 彩云小译 / 腾讯交互翻译 |
| 目标语言 | 源语言自动检测 |
| 翻译速度 | 1–10 条/秒。高峰时多条聊天会合成一次请求，避免把单个引擎打满 |
| 关键词屏蔽 | 原文或译文包含关键词时不显示弹幕 |
| 屏蔽用户列表 | Twitch 原生屏蔽：在面板中查看、添加或取消屏蔽 |
| 弹幕朗读 | 朗读每条弹幕。开启翻译后朗读译文 |
| Super Chat 悬停 | 固定 Cheers、Prime / 层级订阅、高亮付费消息和置顶消息；位置与动画可调，可叠在滚动弹幕上。悬停暂停；可提前关闭 |
| 防页签冻结 | 可选：后台时尽量保持页面「可见」，减轻聊天与播放器被浏览器挂起 |

设置保存在本地，刷新后仍然生效。

## 聊天记录

在直播页或回放页（网址包含 `/videos/`）使用播放器上的下载按钮。

- **直播** — 导出当前聊天面板或（检测到 FrankerFaceZ 时）IRC 缓冲中的消息（不是完整历史），无时间范围
- **FrankerFaceZ** — 直播页检测到 FFZ 时，弹幕改为通过 Twitch IRC 取流，避免与聊天 DOM 冲突
- **回放** — 从 Twitch 拉取历史聊天，可选时间范围
- 可按聊天内容关键词、发送用户名筛选；留空表示不过滤
- 可选择是否包含 Super Chat（Bits Cheers）
- 导出 JSON、CSV 或 TXT；回放下载过程中可暂停、继续或取消
- 若直播面板为空，或 Twitch 已不再保留该回放的聊天，面板会提示

## 开发

```bash
npm run build
npm run watch
```

公开演示不需要构建：[Twitch 弹幕演示](https://saka1zum1.github.io/twitch-danmaku/)。它用页面代替观看页（播放器、控制栏、聊天列表）。列表里已有的消息不会滚动；预热结束后新加的消息会从画面上飘过。顶栏可开关翻译与朗读并与控制栏同步。可试用滚动区域、Super Chat 悬停位置、收藏与独轮车、增强画中画、右键菜单等。开启翻译后可看到演示译文与聊天室译文行。预览页在浏览器标签位于后台时也会继续跑。

## 注意事项

- 翻译依赖 Microsoft、Google、火山、彩云或腾讯服务，部分地区需代理
- 高流量时脚本会把多条消息合并翻译，并把被限流的引擎暂时换掉
- Twitch DOM 更新可能影响兼容性，欢迎提交 Issue
