## What's new

- **Scrolling danmaku color** — In settings, keep Twitch username colors, switch to one uniform color, or pick a custom color. PiP scrolling danmaku follows the same choice.
- **Super Chat compact pin** — The slim pin shows avatar, amount, and tier badge; open the detail card for the full message and quick actions.
- Docs, demo, and Greasy Fork descriptions updated.

**Install / update:** [Greasy Fork](https://greasyfork.org/en/scripts/586579-twitch-danmaku-bullet-chat) or download `twitch-danmaku.user.js` from this release.
